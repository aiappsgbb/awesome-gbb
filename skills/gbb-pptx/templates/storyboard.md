# Presentation content brief

Use this structure or equivalent fields in an existing file. Delete instructions
and unused fields from the deliverable; never ship empty placeholders.
For a small edit, record only changed slides and their dependencies.

## Title-only storyline

List stable slide IDs and titles in sequence. Each substantive slide must have
a distinct role in answering the audience's question. Covers, agendas and
exercises may use labels or questions instead of assertion titles.

## Slide content

Repeat for each relevant slide; omit fields that genuinely do not apply.

- ID and role / audience question:
- Title:
- Visible content: evidence, explanation or example
- Implication and reasoning:
- Material caveat visible beside the claim:
- Representation: text / chart / diagram / table / image, and why it helps
- Notes: explanation, transition and full source locator
- Optional appendix detail:
- Source IDs and claim state: verified / source-reported / interpretation /
  estimate or hypothesis / synthetic / missing or conflicting
- Timing estimate, if relevant:

## Sources and gaps

For consequential facts: source ID, inspected locator, supported claim,
scope/date and limitations. For numbers: unit, population/denominator, period,
baseline, calculation if derived, and observed/estimated/illustrative status.
Record unavailable or contradictory evidence explicitly.
