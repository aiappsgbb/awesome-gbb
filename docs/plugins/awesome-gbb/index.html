v4.35.0 41 skills

Proposed / unreleased Microsoft AI Apps GBB skills catalog — 41 reusable building blocks for Copilot-assisted engagements, including Agent Framework Harness and the unpublished AgentOps, delegated MCP auth, web-experience-design and progress-guard candidates. Covers execution memory and bounded recovery, task-first web UX, Azure infra (azd, Bicep, ACA, ACA Jobs, foundry-mcp-aca-jobs), Foundry agents (prompt agents, hosted agents, harness runtimes, routines, RAG, MCP, evals, observability, AgentOps adoption and release evidence, network runbook), governance (Citadel, AGT), cost analysis, tenant isolation, and enterprise automation. Threadlight pipeline skills moved to threadlight-skills. Zava digital-clone skills moved to zava-constellation. USE FOR: pre-sales engagements, pilots, demos, web experiences, Azure AI, Foundry, or Copilot CLI workflows. DO NOT USE FOR: Threadlight pipeline (use threadlight-skills), Zava workspace (use zava-constellation).
