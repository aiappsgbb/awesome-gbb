pulse-projects

v1.0.0 🛠️ Cross-Cutting Helpers

Persistent per-customer project memory: one curated YAML file per engagement in the user's OneDrive Pulse folder, tracking status, risk, stakeholders, commitments, timeline, artifacts and teammate context. USE FOR: the user mentions a customer, deal, engagement, initiative or stakeholder by name; describes a meeting, email or conversation that affects a known engagement; asks about commitments, status, or who-said-what for named work; creating, updating, curating or auto-archiving engagement records. DO NOT USE FOR: deadline or task tracking (commitments are never deadlines), CRM or pipeline system-of-record updates, or one-off notes with no named engagement.

Install

gh skill install aiappsgbb/awesome-gbb pulse-projects
