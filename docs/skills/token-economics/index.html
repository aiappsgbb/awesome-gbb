token-economics

v1.0.0 🛠️ Cross-Cutting Helpers

Reduce cost per successful task, TPM pressure and context size for Responses API apps and agents. Ordered ladder: prompt/tool-output diet, deferred tool loading with tool_search + defer_loading (gpt-5.4+), cache-friendly prefixes, allowed_tools, reasoning effort/verbosity/max_output_tokens, compaction, model right-sizing, Flex/Batch/Priority. Live-measured script compares eager vs deferred cost, latency and tool selection; shows when deferral loses to a warm cache. USE FOR: token economics, token optimization, reduce token usage, LLM cost, tool_search, defer_loading, deferred tools, tool namespaces, too many tools, large MCP catalog, prompt caching hit rate, cached_tokens, TPM 429 from large prompts, reasoning effort cost, context compaction, flex processing. DO NOT USE FOR: PAYG-vs-PTU sizing (use paygo-ptu-cost-analyzer), Foundry spend dashboards/budgets (use foundry-cost-monitoring), Foundry Toolbox tool search (use foundry-toolbox), hosted-agent cache breakpoints (use foundry-hosted-agents).
