foundry-iq-agent-integration

v3.0.0 🏗️ Foundry Building Blocks

Wire Foundry IQ (Azure AI Search) knowledge bases into agents you build: hosted Agent Framework agents via SDK retrieve tool, KB MCP with httpx.Auth or Toolbox; Agent Service wiring (RemoteTool connection, ProjectManagedIdentity, knowledge_base_retrieve); azd bootstrap hardening. Covers GA REST 2026-10-01 vs 2026-11-01-preview KB MCP, reasoning effort, citations, knowledgeRetrieval billing and query-time permission trimming. USE FOR: knowledge base in a hosted agent, agent RAG, kb-mcp, KB MCP httpx.Auth, knowledge_base_retrieve, Toolbox knowledge base, azd bootstrap Foundry IQ, policy assistant, citations, x-ms-query-source-authorization, permission trimming, knowledgeRetrieval 402. DO NOT USE FOR: entity or topic graphs, ontologies, querying or diagnosing an existing knowledge base (use the official foundry-iq-skills plugin), document extraction (use foundry-doc-vision-speech), MCP server deployment (use foundry-mcp-aca), agent runtime (use foundry-hosted-agents), Work IQ, Fabric IQ or Web IQ.
