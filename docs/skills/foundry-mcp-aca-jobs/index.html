foundry-mcp-aca-jobs

v1.3.2 🏗️ Foundry Building Blocks

Build job-backed MCP servers for Foundry when the control plane must stay responsive and execution belongs in ACA Jobs. USE FOR: MCP Tasks, SEP-2663, ACA Jobs, durable result claims, callbacks, external job orchestration, and shared-image worker handoff. DO NOT USE FOR: producer-side MCP hosting (use foundry-mcp-aca), Service Bus/queue/event-dispatch workflows, or business logic that should run directly in the MCP server or Docket container.
